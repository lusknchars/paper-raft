# Live View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `raft prepare --watch` and `raft bench --watch` (and `raft watch`) show a live local page: which paper and agents, a glowing step network, an honest percentage, what the agent is doing now, and results so far.

**Architecture:** A new `raft/live.py` owns session files in `.raft/live/` (atomic, throttled writes, schema `live`) plus transcript tailing threads. `prepare.py` and `bench.py` drive a `Session` through their existing steps. `watch.py` serves `/live.json` and a new page `live.html` + `live.js` (three.js lines with the flow view's bloom, 2D canvas fallback). Nothing is committed or published.

**Tech Stack:** Python 3.12 (stdlib threading, http.server), jsonschema, pytest; plain ES modules + three 0.186.1 (vendored); Playwright 1.63 for the headless check.

**Spec:** `docs/superpowers/specs/2026-10-15-live-view-design.md`

## Global Constraints

- Live files live in `.raft/live/<kind>-<study>-<UTC time>.json` at the repo root; `.raft/` is gitignored; never committed or published.
- Writes are atomic (temp file then `os.replace`) and at most twice a second, except state changes, which write at once.
- Percentage = finished work units / total work units; never a guess inside an agent step. Elapsed vs timeout is shown separately.
- Activity lines are cut to 160 characters; `stderr_tail` is the last 3 non-blank stderr lines.
- The server stays 127.0.0.1 only with the existing Host check, and only reads files.
- Data text reaches the DOM only through `textContent`.
- The public site does not change: `compare` must not copy `live.html`, `live.js`, `live.css`.
- No Claude co-author or "Generated with Claude Code" lines in commits.

## Review Focus

1. A session file half-written or from an older schema in `.raft/live/` → `raft watch` skips it, never 500s (test in Task 1).
2. The terminal running prepare is killed (no `stop()` call) → page shows `lost`, not `running` forever (Task 1).
3. A transcript that is huge or ends mid-line → tailing reads only the last 256 KB and skips the broken line (Task 2).
4. `--watch` when port 8765 is already taken → the run still starts, with one warning line (Task 5).
5. An agent step raises (evidence tampering, Ctrl-C) while a step is `running` → session ends `stopped`, running step marked `failed`, message kept (Task 3).

```python
"""Live sessions: what `raft prepare` and `raft bench` are doing right now, for `raft watch`.

Each session is one JSON file in .raft/live/ (gitignored, never published), rewritten atomically. The percentage is
finished work units over total work units; nothing here guesses how far an agent is inside a step.
"""
import json
import os
import threading
import time
from datetime import datetime, timezone
from pathlib import Path

from . import schema

LIVE_DIR = Path(".raft") / "live"
KEEP = 20
LINE_MAX = 160
ACTIVITY_KEEP = 6


def _now() -> str:
    return datetime.now(timezone.utc).isoformat(timespec="seconds")


def clip(text: str) -> str:
    s = " ".join(str(text).split())
    return s if len(s) <= LINE_MAX else s[:LINE_MAX - 1] + "…"


class Session:
    def __init__(self, root, kind: str, study: str, *, agents: dict, total: int, title=None, arxiv=None,
                 interval: float = 0.5, on_write=None):
        started = datetime.now(timezone.utc)
        self.path = Path(root) / LIVE_DIR / f"{kind}-{study}-{started:%Y%m%dT%H%M%S%fZ}.json"
        self.interval, self.on_write = interval, on_write
        self._lock = threading.RLock()
        self._last = 0.0
        self._done, self._partial, self._t0 = 0, 0.0, {}
        self.data = {"kind": kind, "study": study, "title": title, "arxiv": arxiv, "pid": os.getpid(),
                     "started_at": started.isoformat(timespec="seconds"), "updated_at": _now(), "state": "running",
                     "agents": agents, "units": {"done": 0, "total": total}, "steps": [], "results": {},
                     "message": None, "next": None}
        self._write(force=True)

    # writing
    def _write(self, force: bool = False) -> None:
        with self._lock:
            now = time.monotonic()
            if not force and now - self._last < self.interval:
                return
            self._last = now
            self.data["updated_at"] = _now()
            self.data["units"]["done"] = round(self._done + self._partial, 3)
            self.path.parent.mkdir(parents=True, exist_ok=True)
            tmp = self.path.with_name(f"{self.path.name}.{os.getpid()}.{threading.get_ident()}.tmp")
            tmp.write_text(json.dumps(self.data, ensure_ascii=False))
            os.replace(tmp, self.path)
            if self.on_write:
                self.on_write(json.loads(json.dumps(self.data)))

    def _step(self, step_id: str) -> dict:
        return next(s for s in self.data["steps"] if s["id"] == step_id)

    # steps
    def begin(self, step_id: str, label: str, *, agent=None, method=None, timeout_s=None) -> None:
        with self._lock:
            self._t0[step_id] = time.monotonic()
            self.data["steps"].append({"id": step_id, "label": label, "state": "running", "agent": agent,
                                       "method": method, "timeout_s": timeout_s, "started_at": _now(),
                                       "wall_s": None, "detail": None, "activity": [], "stderr_tail": None})
            self._write(force=True)

    def end(self, step_id: str, state: str = "done", *, detail=None, unit: bool = True) -> None:
        with self._lock:
            s = self._step(step_id)
            s["state"], s["detail"] = state, detail
            s["wall_s"] = round(time.monotonic() - self._t0.pop(step_id, time.monotonic()), 1)
            self._partial = 0.0
            if unit:
                self._done += 1
            self._write(force=True)

    def skip(self, step_id: str, label: str, detail: str) -> None:
        self.begin(step_id, label)
        self.end(step_id, detail=detail)

    def add_total(self, n: int) -> None:
        with self._lock:
            u = self.data["units"]
            u["total"] = max(self._done, u["total"] + n)
            self._write(force=True)

    def set_partial(self, fraction: float) -> None:
        with self._lock:
            self._partial = min(0.999, max(0.0, float(fraction)))
            self._write()

    def set_activity(self, step_id: str, lines: list[str], stderr_tail) -> None:
        with self._lock:
            s = self._step(step_id)
            old = [a["text"] for a in s["activity"]]
            new = [clip(x) for x in lines][-ACTIVITY_KEEP:]
            if new != old:
                stamp = {a["text"]: a["t"] for a in s["activity"]}
                s["activity"] = [{"t": stamp.get(x, _now()), "text": x} for x in new]
            s["stderr_tail"] = stderr_tail
            self._write()

    def set_results(self, **kw) -> None:
        with self._lock:
            self.data["results"].update(kw)
            self._write(force=True)

    # endings
    def finish(self, next_cmd) -> None:
        with self._lock:
            self.data["state"], self.data["next"] = "finished", next_cmd
            self._write(force=True)

    def stop(self, message: str) -> None:
        with self._lock:
            for s in self.data["steps"]:
                if s["state"] == "running":
                    s["state"] = "failed"
            self.data["state"], self.data["message"] = "stopped", message
            self._write(force=True)


def _alive(pid: int) -> bool:
    try:
        os.kill(pid, 0)
    except ProcessLookupError:
        return False
    except PermissionError:
        return True
    return True


def sessions(root, study=None) -> list[dict]:
    """Every readable session, newest first (at most KEEP); a running one whose process is gone is `lost`."""
    out = []
    for p in (Path(root) / LIVE_DIR).glob("*.json"):
        try:
            s = json.loads(p.read_text())
        except (OSError, json.JSONDecodeError):
            continue
        if not isinstance(s, dict) or schema.errors("live", s) or (study and s["study"] != study):
            continue
        if s["state"] == "running" and not _alive(s["pid"]):
            s["state"] = "lost"
        s["id"] = p.stem
        out.append(s)
    out.sort(key=lambda s: (s["started_at"], s["id"]), reverse=True)
    return out[:KEEP]
```

def _tool_line(name, args) -> str:
    args = args if isinstance(args, dict) else {}
    for k in ("command", "file_path", "path", "pattern", "url"):
        if isinstance(args.get(k), str):
            return f"{name} {args[k]}"
    return str(name)


def activity_lines(agent: str, text: str) -> list[str]:
    """The agent's own words and actions, newest last, from its JSON event stream (unknown formats give none)."""
    out, started = [], set()
    for e in agents._events(text):
        if agent == "claude-code" and e.get("type") == "assistant":
            for c in (e.get("message") or {}).get("content") or []:
                if not isinstance(c, dict):
                    continue
                if c.get("type") == "text" and str(c.get("text", "")).strip():
                    out.append(c["text"])
                elif c.get("type") == "tool_use":
                    out.append(_tool_line(c.get("name"), c.get("input")))
        elif agent == "codex" and e.get("type") in ("item.started", "item.completed"):
            item = e.get("item") or {}
            if item.get("type") == "agent_message" and e["type"] == "item.completed" and str(item.get("text", "")).strip():
                out.append(item["text"])
            elif item.get("type") == "command_execution" and isinstance(item.get("command"), str):
                if e["type"] == "item.started":
                    started.add(item.get("id"))
                elif item.get("id") in started:
                    continue
                out.append("$ " + item["command"])
    return [clip(x) for x in out][-ACTIVITY_KEEP:]


def stderr_tail(text: str):
    lines = [clip(x) for x in text.splitlines() if x.strip()][-3:]
    return "\n".join(lines) or None


def read_tail(path: Path, limit: int = 262_144) -> str:
    try:
        with open(path, "rb") as f:
            f.seek(0, os.SEEK_END)
            f.seek(max(0, f.tell() - limit))
            return f.read().decode("utf-8", errors="replace")
    except OSError:
        return ""


def _loop(every: float, tick):
    stop = threading.Event()

    def run():
        while not stop.wait(every):
            try:
                tick()
            except Exception:  # noqa: BLE001 (a bad read must never kill the run)
                pass
    t = threading.Thread(target=run, daemon=True)
    t.start()
    return stop, t


@contextmanager
def watching(session: Session, step_id: str, agent: str, transcript: Path, every: float = 1.0):
    """While the agent runs, copy its newest events and stderr lines into the step."""
    transcript = Path(transcript)

    def tick():
        session.set_activity(step_id, activity_lines(agent, read_tail(transcript)),
                             stderr_tail(read_tail(transcript.with_suffix(".stderr.txt"), 8192)))
    stop, t = _loop(every, tick)
    try:
        yield
    finally:
        stop.set()
        t.join()
        tick()


@contextmanager
def watching_progress(session: Session, path: Path, every: float = 0.5):
    """While a graded run goes, count the solver's own progress(fraction) reports as part of a unit."""
    def tick():
        try:
            f = json.loads(Path(path).read_text()).get("fraction")
        except (OSError, json.JSONDecodeError, AttributeError):
            return
        if isinstance(f, (int, float)) and not isinstance(f, bool):
            session.set_partial(f)
    stop, t = _loop(every, tick)
    try:
        yield
    finally:
        stop.set()
        t.join()

// Paper Raft live view: what `raft prepare` and `raft bench` are doing right now, as a glowing step network.
// Served only by `raft watch` on 127.0.0.1. Data text only ever reaches the DOM through textContent.
import * as THREE from "three";
import { makeGL } from "./flow.js";

const COLOR = { done: "#6fd9a0", running: "#f2b24c", failed: "#ef7a62", pending: "#3a3631",
                blocked: "#6fd9a0", through: "#ef7a62", paper: "#efe1c6" };
const SEG = 28;

function h(tag, cls, text) {
  const n = document.createElement(tag);
  if (cls) n.className = cls;
  if (text != null) n.textContent = text;
  return n;
}

export function percent(s) {
  const { done, total } = s.units;
  return total > 0 ? Math.min(100, Math.floor((100 * done) / total)) : 0;
}

export function graph(s) {
  const chain = [{ id: "paper", label: s.arxiv ? `arXiv:${s.arxiv}` : s.study, state: "paper", children: [] }];
  const byId = {};
  for (const st of s.steps) {
    if (st.id.startsWith("run-")) continue;
    const n = { id: st.id, label: st.label, state: st.state, children: [] };
    chain.push(n);
    byId[st.id] = n;
  }
  for (const r of (s.results && s.results.rounds) || []) {
    const n = byId[`attack-${r.round}`];
    if (n) n.children = r.attacks.map((a) => ({ label: a.name, state: a.blocked ? "blocked" : "through" }));
  }
  for (const st of s.steps) {
    if (!st.id.startsWith("run-")) continue;
    const n = byId[`implement-${st.method}`];
    if (n) n.children.push({ label: st.label, state: st.state });
  }
  if (s.state === "running" && !s.steps.some((st) => st.state === "running")) {
    chain.push({ id: "next", label: "…", state: "pending", children: [] });
  }
  return chain;
}

function fmt(sec) {
  sec = Math.max(0, Math.round(sec));
  const m = Math.floor(sec / 60), s = sec % 60;
  return m >= 60 ? `${Math.floor(m / 60)}h ${m % 60}m` : m ? `${m}m ${s}s` : `${s}s`;
}

function curve(a, b, bend) {
  const pts = [];
  for (let k = 0; k <= SEG; k++) {
    const u = k / SEG, s = 1 - u;
    const c1 = { x: a.x + (b.x - a.x) * bend, y: a.y }, c2 = { x: b.x - (b.x - a.x) * bend, y: b.y };
    pts.push({ x: s * s * s * a.x + 3 * s * s * u * c1.x + 3 * s * u * u * c2.x + u * u * u * b.x,
               y: s * s * s * a.y + 3 * s * s * u * c1.y + 3 * s * u * u * c2.y + u * u * u * b.y, u });
  }
  return pts;
}

function ring(c, r) {
  const pts = [];
  for (let k = 0; k <= SEG; k++) { const t = (k / SEG) * Math.PI * 2; pts.push({ x: c.x + r * Math.cos(t), y: c.y + r * Math.sin(t), u: k / SEG }); }
  return pts;
}

export function mountLive(root, opts = {}) {
  const reduce = window.matchMedia("(prefers-reduced-motion: reduce)").matches;
  const force2d = opts.force2d || new URLSearchParams(window.location.search).has("flow2d");
  root.classList.add("lv");
  if (opts.compact) root.classList.add("lv-compact");
  const side = h("nav", "lv-side"), main = h("section", "lv-main");
  const head = h("header", "lv-head"), stage = h("div", "lv-stage"), labels = h("div", "lv-labels");
  const bar = h("div", "lv-bar"), track = h("div", "lv-track"), fill = h("i"), pct = h("span", "lv-pct");
  const timer = h("div", "lv-timer"), who = h("div", "lv-who"), act = h("ul", "lv-activity");
  const stderr = h("pre", "lv-stderr"), results = h("div", "lv-results"), end = h("p", "lv-end");
  track.append(fill); bar.append(track, pct); stage.append(labels);
  main.append(head, stage, bar, timer, who, act, stderr, results, end);
  root.replaceChildren(...(opts.compact ? [main] : [side, main]));

  let gl = null;
  if (!force2d) { try { gl = makeGL(); } catch { gl = null; } }
  const canvas = gl ? gl.renderer.domElement : document.createElement("canvas");
  const ctx = gl ? null : canvas.getContext("2d");
  canvas.className = "lv-canvas";
  stage.prepend(canvas);
  root.dataset.lvRenderer = gl ? "webgl" : "2d";

  let sessions = [], picked = null, strokes = [], shape = "", W = 0, H = 0, raf = 0, timerId = null, destroyed = false;

  function current() {
    const list = opts.study ? sessions.filter((s) => s.study === opts.study) : sessions;
    return list.find((s) => s.id === picked) || list.find((s) => s.state === "running") || list[0] || null;
  }

  function layout(s) {
    W = stage.clientWidth; H = stage.clientHeight;
    const nodes = graph(s), n = nodes.length, x0 = W * 0.07, dx = n > 1 ? (W * 0.86) / (n - 1) : 0, y = H * 0.36;
    strokes = []; labels.replaceChildren();
    nodes.forEach((node, i) => {
      node.p = { x: x0 + i * dx, y };
      const color = COLOR[node.state] || COLOR.pending;
      if (i) strokes.push({ pts: curve(nodes[i - 1].p, node.p, 0.4), color, live: node.state === "running", a: node.state === "pending" ? 0.25 : 0.8 });
      strokes.push({ pts: ring(node.p, node.id === "paper" ? 9 : 7), color, live: node.state === "running", ring: true, a: 1 });
      const lab = h("div", "lv-label", node.label);
      lab.dataset.s = node.state;
      lab.style.left = `${node.p.x}px`; lab.style.top = `${y + 14}px`;
      lab.style.maxWidth = `${Math.max(48, dx - 6)}px`;
      labels.append(lab);
      const k = node.children.length, gap = Math.min(16, (dx || W * 0.5) / Math.max(1, k));
      node.children.forEach((c, j) => {
        const p = { x: node.p.x + (j - (k - 1) / 2) * gap, y: H * 0.8 };
        const cc = COLOR[c.state] || COLOR.pending;
        strokes.push({ pts: curve(node.p, p, 0.1), color: cc, live: c.state === "running", a: 0.35 });
        strokes.push({ pts: ring(p, 3.5), color: cc, live: c.state === "running", ring: true, a: 1 });
      });
    });
    for (const st of strokes) st.rgb = new THREE.Color(st.color);
    geometry();
  }

  function geometry() {
    const dpr = Math.min(window.devicePixelRatio || 1, 2);
    if (!gl) { canvas.width = W * dpr; canvas.height = H * dpr; ctx.setTransform(dpr, 0, 0, dpr, 0, 0); return; }
    gl.renderer.setSize(W, H, false); gl.composer.setSize(W, H);
    Object.assign(gl.camera, { left: 0, right: W, top: H, bottom: 0 }); gl.camera.updateProjectionMatrix();
    if (gl.lines) { gl.scene.remove(gl.lines); gl.lines.geometry.dispose(); gl.lines.material.dispose(); }
    const n = strokes.reduce((t, st) => t + (st.pts.length - 1) * 2, 0);
    gl.pos = new Float32Array(n * 3); gl.col = new Float32Array(n * 3); gl.U = new Float32Array(n); gl.C = new Uint32Array(n);
    let v = 0;
    strokes.forEach((st, si) => {
      for (let k = 0; k < st.pts.length - 1; k++) for (const p of [st.pts[k], st.pts[k + 1]]) {
        gl.pos[v * 3] = p.x; gl.pos[v * 3 + 1] = H - p.y; gl.U[v] = p.u; gl.C[v] = si; v++;
      }
    });
    const g = new THREE.BufferGeometry();
    g.setAttribute("position", new THREE.BufferAttribute(gl.pos, 3));
    g.setAttribute("color", new THREE.BufferAttribute(gl.col, 3));
    gl.lines = new THREE.LineSegments(g, new THREE.LineBasicMaterial({ vertexColors: true, transparent: true,
      depthWrite: false, blending: THREE.AdditiveBlending }));
    gl.scene.add(gl.lines);
  }

  function paint(t) {
    const pulse = reduce ? 0 : 1;
    if (gl) {
      const { col, U, C } = gl;
      for (let v = 0; v < U.length; v++) {
        const st = strokes[C[v]];
        let a = st.a * 0.55;
        if (st.live && pulse) {
          if (st.ring) a *= 0.6 + 0.4 * Math.sin(t * 4);
          else { const d = U[v] - ((t * 0.6) % 1); a += 0.9 * Math.exp(-(d * d) / 0.003); }
        }
        col[v * 3] = st.rgb.r * a; col[v * 3 + 1] = st.rgb.g * a; col[v * 3 + 2] = st.rgb.b * a;
      }
      gl.lines.geometry.attributes.color.needsUpdate = true;
      gl.composer.render();
      return;
    }
    ctx.globalCompositeOperation = "source-over";
    ctx.fillStyle = "#030305"; ctx.fillRect(0, 0, W, H);
    ctx.globalCompositeOperation = "lighter";
    ctx.lineWidth = 1.2;
    for (const st of strokes) {
      const a = st.live && pulse && st.ring ? st.a * (0.6 + 0.4 * Math.sin(t * 4)) : st.a;
      ctx.strokeStyle = `rgba(${Math.round(st.rgb.r * 255)},${Math.round(st.rgb.g * 255)},${Math.round(st.rgb.b * 255)},${a})`;
      ctx.shadowColor = st.color; ctx.shadowBlur = 8;
      ctx.beginPath(); ctx.moveTo(st.pts[0].x, st.pts[0].y);
      for (const p of st.pts.slice(1)) ctx.lineTo(p.x, p.y);
      ctx.stroke();
    }
  }

  function frame(ms) {
    raf = 0;
    if (destroyed || !strokes.length) return;
    paint(ms / 1000);
    if (!reduce && strokes.some((st) => st.live)) raf = requestAnimationFrame(frame);
  }
  function kick() { if (!destroyed && !raf) raf = requestAnimationFrame(frame); }

  function cell(label, value) {
    const c = h("div", "lv-cell");
    c.append(h("div", "l", label), h("div", "v", value));
    return c;
  }

  function render() {
    const s = current();
    side.replaceChildren();
    const list = opts.study ? sessions.filter((x) => x.study === opts.study) : sessions;
    for (const x of list) {
      const b = h("button", null, `${x.kind} · ${x.study}`);
      b.type = "button";
      b.append(h("small", null, `${x.state} · ${percent(x)}% · ${x.started_at.slice(0, 16).replace("T", " ")}`));
      b.setAttribute("aria-pressed", String(s && x.id === s.id));
      b.addEventListener("click", () => { picked = x.id; render(); });
      side.append(b);
    }
    root.hidden = !!opts.compact && !(s && s.state === "running");
    if (!s) {
      main.replaceChildren(h("p", "lv-empty", "No prepare or bench sessions on this machine yet. Start one with `uv run raft prepare --arxiv <id> --agent claude-code --watch`."));
      strokes = []; return;
    }
    if (main.firstChild?.className === "lv-empty") main.replaceChildren(head, stage, bar, timer, who, act, stderr, results, end);

    head.replaceChildren();
    const h1 = h("h1");
    if (s.arxiv) { const a = h("a", null, s.title || s.study); a.href = `https://arxiv.org/abs/${encodeURIComponent(s.arxiv)}`; a.target = "_blank"; a.rel = "noopener"; h1.append(a); }
    else h1.textContent = s.title || s.study;
    const chips = h("div", "lv-chips");
    const state = h("span", "lv-chip lv-state", s.state); state.dataset.s = s.state;
    chips.append(state, h("span", "lv-chip", s.kind === "bench" ? `bench · ${s.study}` : `prepare · ${s.study}`));
    for (const [role, a] of Object.entries(s.agents)) chips.append(h("span", "lv-chip", `${role}: ${a.tool}${a.model ? " · " + a.model : ""}`));
    head.append(h1, chips);

    const key = JSON.stringify([s.id, s.steps.map((st) => [st.id, st.state]), s.results.rounds, stage.clientWidth, stage.clientHeight]);
    if (key !== shape) { shape = key; layout(s); }
    kick();

    const p = percent(s);
    fill.style.width = `${p}%`;
    fill.style.background = s.state === "stopped" || s.state === "lost" ? "var(--lv-bad)" : p === 100 ? "var(--lv-ok)" : "var(--lv-run)";
    pct.textContent = `${p}% · ${+s.units.done.toFixed(2)} / ${s.units.total} steps`;

    const run = [...s.steps].reverse().find((st) => st.state === "running");
    const last = run || [...s.steps].reverse().find((st) => st.activity.length || st.stderr_tail);
    if (run) {
      const el = (Date.now() - Date.parse(run.started_at)) / 1000;
      timer.textContent = `${run.label} · ${fmt(el)}` + (run.timeout_s ? ` of ${fmt(run.timeout_s)}` : "");
    } else timer.textContent = "";
    const role = last && last.agent && s.agents[last.agent];
    who.textContent = last && last.activity.length ? `${role ? role.tool : "agent"} says (its own words, not a result)` : "";
    act.replaceChildren(...(last ? last.activity.map((a) => h("li", null, a.text)) : []));
    stderr.hidden = !(last && last.stderr_tail);
    stderr.textContent = last && last.stderr_tail ? last.stderr_tail : "";

    results.replaceChildren();
    const r = s.results || {};
    if (s.kind === "prepare") {
      if (r.holes != null) results.append(cell("checker holes", String(r.holes)));
      for (const rd of r.rounds || []) results.append(cell(`round ${rd.round}`, `${rd.blocked}/${rd.tried} blocked`));
    } else if (r.expected != null) {
      results.append(cell("passed", `${r.passed} / ${r.expected}`), cell("failed", String(r.failed)),
                     cell("score", `${Math.round(100 * r.score)}%`));
    }

    end.textContent = s.state === "finished" ? `Next: ${s.next}` : s.state === "stopped" ? s.message || "stopped"
      : s.state === "lost" ? "The terminal running this session is gone; rerun the command to resume." : "";
  }

  async function poll() {
    if (destroyed) return;
    try {
      const r = await fetch(opts.url || "/live.json", { cache: "no-store" });
      if (r.ok) { const j = await r.json(); if (Array.isArray(j)) { sessions = j; render(); } }
    } catch { /* the server went away; keep the last state */ }
  }
  poll();
  timerId = setInterval(poll, opts.interval || 1000);
  const ro = new ResizeObserver(() => { shape = ""; if (current()) render(); });
  ro.observe(stage);

  return {
    destroy() {
      destroyed = true; clearInterval(timerId); ro.disconnect();
      if (raf) cancelAnimationFrame(raf);
      if (gl) { if (gl.lines) { gl.lines.geometry.dispose(); gl.lines.material.dispose(); } gl.renderer.dispose(); gl.renderer.forceContextLoss(); }
      root.replaceChildren(); root.classList.remove("lv", "lv-compact");
    },
  };
}
