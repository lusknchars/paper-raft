# Bench Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `raft bench` gives a study to someone's own agent setup (Claude Code, Codex, or any command) in a blind workspace, grades its code with the study's own measure out of the agent's reach, writes a verifiable entry, and shows every entry on a public scoreboard.

**Architecture:** Three new modules. `raft/agents.py` knows how to start each tool headless and read back the tokens and cost it reports. `raft/bench.py` builds the blind workspace, runs the agent per method, grades the code in a fresh copy of `problem/` with the existing `runner.execute`, writes `bench/results/<study>/<id>/`, and re-verifies entries. `raft/benchboard.py` is pure functions: score, metrics, ranking, markdown table, site rows. `raft compare` puts the board into `data.json`, and `app.js` gets a `#bench` view.

**Tech Stack:** Python 3.11+ standard library (subprocess, tempfile, difflib, shlex), numpy, jsonschema and pyyaml (already dependencies), plain JavaScript on the site, Playwright for the headless check.

**Spec:** `docs/superpowers/specs/2026-10-15-bench-design.md`

## Global Constraints

- Work in `~/paper-raft` on branch `bench`. Run tests with `uv run pytest -q`; the whole suite stays green after every task.
- No new dependencies in `pyproject.toml` or `package.json`.
- Never edit `studies/*/problem/` and never change a tolerance.
- Commit messages are plain: **no `Co-Authored-By` or "Generated with" lines of any kind.**
- Never commit PDFs (`papers/` is gitignored).
- Grading uses only the harness's own runs of the agent's code, in a checkout the agent never touched. Failures are recorded like passes.
- Tokens, cost and time are labelled **self-reported** (or marked with `*` and a footnote saying "reported by the agent's tool, not verified") on every surface that shows them.
- The scoreboard says entries are graded automatically and **not reviewed**.

## Decisions beyond the spec (rulings)

1. **Workspace is a whitelist, not a blacklist:** only `studies/<s>/paper.yaml`, `extraction.json`, `problem/setup.py`, an empty `methods/`, the PDF if present locally, and the setup overlay. This keeps `.claude/`, `adapters/`, `docs/` (plans that describe the lab's solutions) and `.superpowers/` out.
2. **Python for the agent:** the brief names `sys.executable` of the raft environment (numpy and scipy installed there), because Codex runs with network off and cannot `uv sync`.
3. **Copy check:** an agent runs on the owner's machine, where the lab's code is on disk. Grading compares each agent solver with the lab's solver of the same name (line-based `difflib` ratio). At 0.8 or above the method counts as failing with the reason "matches the lab's own code", and `copied_from_lab` is true.
4. **"Full" is decided when the board is built, not stored:** an entry is full when its methods cover every method the study has now. If a study gains a method, older entries move to partial instead of failing CI.
5. **stderr** is kept next to the transcript as `transcript/<m>.stderr.txt` (same 2 MB trim).

## Review Focus

1. The agent's CLI is not installed → a one-line `raft: claude not found…` exit, no traceback (Task 4 test).
2. The agent hangs or starts children that outlive it → the whole process group is killed at the timeout, the method is recorded `timed_out`, and the next method still runs (Task 4 test with a grandchild).
3. A `--setup` folder that contains `studies/` or `.git` → `studies/` is refused, `.git` is skipped (Task 2 test).
4. The agent writes outside its folder in the workspace (for example, edits the workspace's `setup.py`), or leaves no `solver.py` → grading is unaffected and uses the repo's `problem/`; a missing solver fails every run with "no solver.py" (Task 3 tests).
5. `problem/` has uncommitted changes, or changed after an entry was made → bench refuses to start; verify reports "problem changed since this entry" (Task 5 tests).

- [ ] **Step 4: Write `raft/benchboard.py`**

```python
"""Score, rank and print bench entries: pure functions over entry dicts (raft/contracts/bench-entry.schema.json)."""
import math
from pathlib import Path

from . import runner, schema

AGG = {"max": max, "min": min, "mean": lambda v: sum(v) / len(v)}
FOOTNOTE = ("*Reported by the agent's tool, not verified. Scores are graded by the study's own measure, "
            "in a copy the agent never saw, and are not reviewed.")


def aggregate_metrics(specs: list[dict], methods: list[dict]) -> list[dict]:
    """The study's paper.yaml metrics over every run that has the error key (same rule as the flow view)."""
    out = []
    for s in specs:
        vals = []
        for m in methods:
            for r in m["runs"]:
                errs = r.get("errors") or {}
                if s["from"] in errs and all(r["params"].get(k) == v for k, v in s.get("where", {}).items()):
                    v = float(errs[s["from"]])
                    vals.append(v if math.isfinite(v) else 1e300)
        out.append({"key": s["key"], "label": s["label"], "note": s["note"], "format": s["format"],
                    "value": AGG[s["agg"]](vals) if vals else None})
    return out


def score_counts(methods: list[dict]) -> dict:
    return {"passed": sum(bool(r["pass"]) for m in methods for r in m["runs"]),
            "expected": sum(len(m["runs"]) for m in methods)}


def totals(entry: dict) -> dict:
    ms = entry["methods"]

    def total(key):
        vals = [m["usage"][key] for m in ms]
        return None if any(v is None for v in vals) else sum(vals)

    return {"wall_s": round(sum(m["wall_s"] for m in ms), 1), "input_tokens": total("input_tokens"),
            "output_tokens": total("output_tokens"), "cost_usd": total("cost_usd")}


def fraction(entry: dict) -> float:
    s = entry["score"]
    return s["passed"] / s["expected"] if s["expected"] else 0.0


def is_full(entry: dict, lab: list[str]) -> bool:
    return bool(lab) and set(lab) <= {m["name"] for m in entry["methods"]}


def _key(entry: dict):
    t = totals(entry)
    return (-fraction(entry), math.inf if t["cost_usd"] is None else t["cost_usd"], t["wall_s"], entry["id"])


def ranked(entries: list[dict], lab: list[str]) -> dict:
    return {"full": sorted((e for e in entries if is_full(e, lab)), key=_key),
            "partial": sorted((e for e in entries if not is_full(e, lab)), key=_key)}


def load_all(root: Path) -> dict[str, list[dict]]:
    out: dict[str, list[dict]] = {}
    for p in sorted((Path(root) / "bench" / "results").glob("*/*/entry.json")):
        e = schema.load("bench-entry", p)
        if e["study"] != p.parent.parent.name or e["id"] != p.parent.name:
            raise schema.ContractError(f"{p}: study and id do not match the folder")
        out.setdefault(e["study"], []).append(e)
    return out


def _lab(root: Path, study: str) -> list[str]:
    return runner.methods(Path(root) / "studies" / study)


def entrant_name(entry: dict) -> str:
    a = entry["entrant"]
    return a["agent"] + (f" · {a['model']}" if a["model"] else "") + (" (local)" if a["oss"] else "")


def row(entry: dict, repo: str | None, commit: str | None) -> dict:
    ok = repo and commit and commit != "unknown"
    url = f"{repo}/tree/{commit}/bench/results/{entry['study']}/{entry['id']}" if ok else None
    return {"id": entry["id"], "entrant": entrant_name(entry), "label": entry["entrant"]["label"],
            "passed": entry["score"]["passed"], "expected": entry["score"]["expected"],
            "score": round(fraction(entry), 4), "methods": len(entry["methods"]), **totals(entry),
            "metrics": entry["metrics"], "url": url, "created_at": entry["created_at"]}


def board(root: Path, repo: str | None, commit: str | None) -> dict:
    out = {}
    for study, entries in sorted(load_all(root).items()):
        r = ranked(entries, _lab(root, study))
        out[study] = {k: [row(e, repo, commit) for e in v] for k, v in r.items()}
    return out


def _cell(text) -> str:
    return str(text).replace("|", "\\|")


def table(root: Path, study: str | None = None) -> str:
    lines = []
    for sid, entries in sorted(load_all(root).items()):
        if study and sid != study:
            continue
        r = ranked(entries, _lab(root, sid))
        lines += [f"### {sid}", "", "| # | Agent | Setup | Score | Time | Tokens* | Cost* |",
                  "|---|---|---|---|---|---|---|"]
        for kind in ("full", "partial"):
            for i, e in enumerate(r[kind], 1):
                t = totals(e)
                tokens = ("—" if t["input_tokens"] is None or t["output_tokens"] is None
                          else f"{(t['input_tokens'] + t['output_tokens']) / 1000:.0f}k")
                cost = "—" if t["cost_usd"] is None else f"${t['cost_usd']:.2f}"
                rank = str(i) if kind == "full" else "partial"
                lines.append(f"| {rank} | {_cell(entrant_name(e))} | {_cell(e['entrant']['label'] or '—')} | "
                             f"{e['score']['passed']}/{e['score']['expected']} | {t['wall_s'] / 60:.0f} min | "
                             f"{tokens} | {cost} |")
        lines += ["", FOOTNOTE, ""]
    return "\n".join(lines).rstrip() if lines else "No bench entries yet."
```

```python
"""raft bench: hand a study to someone's agent in a blind workspace, grade its code out of its reach, write an entry.

The workspace holds only the study's paper.yaml, extraction.json, problem/setup.py, an empty methods/ folder, the
PDF if it is here, and the entrant's setup folder, with a fresh git history. The yardstick (measure.py,
reference.json), the lab's methods, runs and reviews are not in it. Grading copies the agent's method folders into
a fresh copy of the study's problem/ and runs them with the same runner `raft run` uses. Nothing the agent says
counts.
"""
import hashlib
import shutil
import subprocess
import sys
from pathlib import Path

import yaml

from . import briefs, provenance

_IGNORE = shutil.ignore_patterns("__pycache__", "*.pyc", ".git")


def _study_dir(root: Path, study: str) -> Path:
    return Path(root) / "studies" / study


def _paper(sd: Path) -> dict:
    return yaml.safe_load((sd / "paper.yaml").read_text()) or {}


def problem_hash(sd: Path) -> str:
    return provenance.inputs_hash({}, Path(sd) / "problem")


def require_clean(root: Path, study: str) -> None:
    sd = _study_dir(root, study)
    if provenance.is_dirty(root, [sd / "problem", sd / "paper.yaml", sd / "extraction.json"]):
        raise SystemExit(f"raft: studies/{study} has uncommitted changes in problem/, paper.yaml or "
                         "extraction.json; commit them first")


def _setup_files(setup: Path) -> list[Path]:
    return sorted(p for p in setup.rglob("*")
                  if p.is_file() and not {".git", "__pycache__"} & set(p.relative_to(setup).parts))


def setup_info(setup: Path | None) -> dict | None:
    if setup is None:
        return None
    setup = Path(setup)
    h = hashlib.sha256()
    files = _setup_files(setup)
    for p in files:
        h.update(p.relative_to(setup).as_posix().encode() + b"\0")
        h.update(p.read_bytes())
    return {"hash": h.hexdigest(), "files": [p.relative_to(setup).as_posix() for p in files][:200]}


def make_workspace(root: Path, study: str, ws: Path, setup: Path | None) -> Path:
    root, ws = Path(root), Path(ws)
    if setup is not None:
        setup = Path(setup)
        if not setup.is_dir():
            raise SystemExit(f"raft: --setup {setup} is not a folder")
        if (setup / "studies").exists():
            raise SystemExit("raft: the --setup folder must not contain studies/; it is copied onto the workspace root")
    sd = _study_dir(root, study)
    wsd = ws / "studies" / study
    (wsd / "problem").mkdir(parents=True)
    (wsd / "methods").mkdir()
    shutil.copyfile(sd / "paper.yaml", wsd / "paper.yaml")
    if (sd / "extraction.json").is_file():
        shutil.copyfile(sd / "extraction.json", wsd / "extraction.json")
    shutil.copyfile(sd / "problem" / "setup.py", wsd / "problem" / "setup.py")
    pdf = _paper(sd).get("pdf")
    if pdf and not Path(pdf).is_absolute() and ".." not in Path(pdf).parts and (root / pdf).is_file():
        (ws / pdf).parent.mkdir(parents=True, exist_ok=True)
        shutil.copyfile(root / pdf, ws / pdf)
    if setup is not None:
        shutil.copytree(setup, ws, dirs_exist_ok=True, ignore=_IGNORE)
    for args in (("init", "-q", "-b", "main"), ("add", "-A"),
                 ("-c", "user.name=raft-bench", "-c", "user.email=bench@paper-raft.invalid",
                  "-c", "commit.gpgsign=false", "commit", "-qm", "workspace")):
        subprocess.run(["git", *args], cwd=ws, check=True, capture_output=True)
    return ws


def render_brief(root: Path, study: str, method: str) -> str:
    return briefs.render(Path(root), "bench-implementer", study, method).replace("{{python}}", sys.executable)
```

```python
OVERLAP = 0.8  # an agent solver at least this similar to the lab's own solver counts as copied


def _code_lines(d: Path) -> list[str]:
    d = Path(d)
    if not d.is_dir():
        return []
    lines = []
    for p in sorted(d.rglob("*.py")):
        if "__pycache__" not in p.parts:
            lines += [s.strip() for s in p.read_text(errors="replace").splitlines() if s.strip()]
    return lines


def lab_overlap(lab_dir: Path, agent_dir: Path) -> float:
    a, b = _code_lines(lab_dir), _code_lines(agent_dir)
    if not a or not b:
        return 0.0
    return difflib.SequenceMatcher(None, a, b, autojunk=False).ratio()


def _finite(errors):
    if errors is None:
        return None
    return {k: (float(v) if math.isfinite(float(v)) else 1e300) for k, v in errors.items()}


def grade(root: Path, study: str, code_dir: Path, methods: list[str], run_timeout: float,
          log=lambda s: None) -> list[dict]:
    """Run the agent's method folders against a fresh copy of the study's committed problem/."""
    sd = _study_dir(root, study)
    with tempfile.TemporaryDirectory(prefix="raft-grade-") as tmp:
        g = Path(tmp) / "studies" / study
        shutil.copytree(sd / "problem", g / "problem", ignore=_IGNORE)
        shutil.copyfile(sd / "paper.yaml", g / "paper.yaml")
        (g / "methods").mkdir()
        combos = runner.expand(g, {})
        out = []
        for m in methods:
            src, dst = Path(code_dir) / m, g / "methods" / m
            has = (src / "solver.py").is_file()
            copied = has and lab_overlap(sd / "methods" / m, src) >= OVERLAP
            res = {"name": m, "guard": [], "copied_from_lab": copied, "runs": []}
            if has:
                shutil.copytree(src, dst, ignore=_IGNORE)
                res["guard"] = guard.scan_method(dst)
            for p in combos:
                rid = runner.run_id(m, p)
                if not has or copied:
                    run = {"run_id": rid, "params": p, "status": "failed", "pass": False,
                           "reason": "no solver.py" if not has else "matches the lab's own code", "errors": None}
                else:
                    _, r = runner.execute(g, m, p, run_timeout)
                    run = {"run_id": rid, "params": p, "status": r["status"], "pass": bool(r["pass"]),
                           "reason": r.get("reason"), "errors": _finite(r.get("errors"))}
                log(f"{'✓' if run['pass'] else '✗'} {rid}" + (f": {run['reason']}" if run["reason"] else ""))
                res["runs"].append(run)
            out.append(res)
        return out
```

```python
"""How raft bench starts each agent tool headless, and what it reads back about tokens and cost.

Tokens and cost are whatever the tool reports about itself; the bench labels them self-reported.
"""
import json
import os
import shlex
import signal
import subprocess
import time
from pathlib import Path

AGENTS = ("claude-code", "codex", "command")
EXE = {"claude-code": "claude", "codex": "codex"}
CLAUDE_TOOLS = "Bash,Read,Edit,Write,Glob,Grep"
ISOLATION = {
    "claude-code": "web tools disallowed; the shell is not network-isolated",
    "codex": "codex sandbox workspace-write (network off unless the user's codex config turns it on)",
    "command": "none enforced by raft",
}


def check(agent: str, *, model=None, oss=False, cmd=None) -> None:
    if agent not in AGENTS:
        raise SystemExit(f"raft: --agent must be one of {', '.join(AGENTS)}")
    if (agent == "command") != bool(cmd):
        raise SystemExit("raft: --cmd goes with --agent command, and only with it")
    if oss and agent != "codex":
        raise SystemExit("raft: --oss works with --agent codex only")
    if agent == "command" and "{brief}" not in cmd:
        raise SystemExit("raft: --cmd must contain {brief}, the path of the task file")


def argv(agent: str, workspace: Path, brief: Path, method: str, *, model=None, oss=False,
         cmd=None) -> tuple[list[str], bool]:
    if agent == "claude-code":
        args = ["claude", "-p", "--output-format", "stream-json", "--verbose",
                "--allowedTools", CLAUDE_TOOLS, "--disallowedTools", "WebFetch,WebSearch"]
        return args + (["--model", model] if model else []), True
    if agent == "codex":
        args = ["codex", "exec", "--json", "--sandbox", "workspace-write", "--skip-git-repo-check",
                "-C", str(workspace)]
        return args + (["-m", model] if model else []) + (["--oss"] if oss else []) + ["-"], True
    fill = {"{brief}": str(brief), "{workspace}": str(workspace), "{method}": method}
    out = []
    for part in shlex.split(cmd):
        for k, v in fill.items():
            part = part.replace(k, v)
        out.append(part)
    return out, False


def tool_version(agent: str) -> str | None:
    if agent not in EXE:
        return None
    try:
        out = subprocess.run([EXE[agent], "--version"], capture_output=True, text=True, timeout=30)
    except (OSError, subprocess.TimeoutExpired):
        return None
    lines = (out.stdout or out.stderr).strip().splitlines()
    return lines[0][:120] if lines else None


def _blank() -> dict:
    return {"input_tokens": None, "cached_input_tokens": None, "output_tokens": None, "cost_usd": None, "turns": None}


def _events(text: str):
    for line in text.splitlines():
        line = line.strip()
        if not line.startswith("{"):
            continue
        try:
            obj = json.loads(line)
        except json.JSONDecodeError:
            continue
        if isinstance(obj, dict):
            yield obj


def _int(v) -> int:
    return int(v) if isinstance(v, (int, float)) and not isinstance(v, bool) and v >= 0 else 0


def parse_usage(agent: str, text: str) -> dict:
    u = _blank()
    if agent == "claude-code":
        result = None
        for e in _events(text):
            if e.get("type") == "result":
                result = e
        if result is not None:
            us = result.get("usage") or {}
            u["input_tokens"] = sum(_int(us.get(k)) for k in
                                    ("input_tokens", "cache_creation_input_tokens", "cache_read_input_tokens"))
            u["cached_input_tokens"] = _int(us.get("cache_read_input_tokens"))
            u["output_tokens"] = _int(us.get("output_tokens"))
            cost = result.get("total_cost_usd")
            ok = isinstance(cost, (int, float)) and not isinstance(cost, bool) and cost >= 0
            u["cost_usd"] = round(float(cost), 6) if ok else None
            u["turns"] = _int(result["num_turns"]) if "num_turns" in result else None
    elif agent == "codex":
        turns = [e for e in _events(text) if e.get("type") == "turn.completed"]
        if turns:
            for k in ("input_tokens", "cached_input_tokens", "output_tokens"):
                u[k] = sum(_int((e.get("usage") or {}).get(k)) for e in turns)
            u["turns"] = len(turns)
    return u


def _kill(proc: subprocess.Popen) -> None:
    try:
        os.killpg(proc.pid, signal.SIGKILL)
    except ProcessLookupError:
        pass
    proc.wait()


def run(agent: str, brief: Path, workspace: Path, method: str, *, model=None, oss=False, cmd=None,
        timeout: float, transcript: Path) -> dict:
    """Start the tool in the workspace, feed it the brief, stop it at the timeout (with everything it started)."""
    args, on_stdin = argv(agent, Path(workspace), Path(brief), method, model=model, oss=oss, cmd=cmd)
    transcript = Path(transcript)
    timed_out = False
    t0 = time.monotonic()
    with open(transcript, "wb") as out, open(transcript.with_suffix(".stderr.txt"), "wb") as err:
        try:
            proc = subprocess.Popen(args, cwd=workspace, stdin=subprocess.PIPE if on_stdin else subprocess.DEVNULL,
                                    stdout=out, stderr=err, start_new_session=True)
        except FileNotFoundError:
            raise SystemExit(f"raft: {args[0]} not found; install it or choose another --agent") from None
        try:
            proc.communicate(input=Path(brief).read_bytes() if on_stdin else None, timeout=timeout)
        except subprocess.TimeoutExpired:
            timed_out = True
            _kill(proc)
        except BaseException:
            _kill(proc)
            raise
        if not timed_out:
            try:  # the tool exited; stop anything it left running in its group
                os.killpg(proc.pid, signal.SIGKILL)
            except (ProcessLookupError, PermissionError):
                pass
    return {"exit": None if timed_out else proc.returncode, "timed_out": timed_out,
            "wall_s": round(time.monotonic() - t0, 1),
            "usage": parse_usage(agent, transcript.read_text(errors="replace"))}
```

```python
def _slug(text: str) -> str:

def _code_hash(code_dir: Path, methods: list[str]) -> str:
    h = hashlib.sha256()
    for m in methods:
        d = Path(code_dir) / m
        for p in sorted(d.rglob("*")) if d.is_dir() else []:
            if p.is_file() and "__pycache__" not in p.parts:

def trim_copy(src: Path, dst: Path, limit: int = TRANSCRIPT_LIMIT) -> None:
    data = Path(src).read_bytes() if Path(src).is_file() else b""

    if a is None or b is None:
        return a is b

def verify(root: Path, entry_dir: Path, run_timeout: float = 1800.0, log=lambda s: None) -> list[str]:
    """Rerun an entry's code against today's problem/ and check every recorded number."""
    root, entry_dir = Path(root).resolve(), Path(entry_dir).resolve()
    try:
        entry = schema.load("bench-entry", entry_dir / "entry.json")
    except schema.ContractError as e:
        return [str(e)]
    eid, study = entry["id"], entry["study"]
    if entry_dir.name != eid or entry_dir.parent.name != study:
        return [f"{entry_dir.name}: study and id do not match the folder"]
    sd = _study_dir(root, study)
    if not (sd / "paper.yaml").is_file():
        return [f"{eid}: unknown study {study!r}"]
    if problem_hash(sd) != entry["problem_hash"]:
        return [f"{eid}: studies/{study}/problem changed since this entry; rerun the bench"]
    names = [m["name"] for m in entry["methods"]]
    graded = grade(root, study, entry_dir / "methods", names, run_timeout, log)
    setup_mod = runner.load_module(sd / "problem" / "setup.py", f"raft_bench_{study.replace('-', '_')}")
    rtol = float(getattr(setup_mod, "REPRO_RTOL", 1e-8))
    problems = []
    for old, new in zip(entry["methods"], graded):
        n = old["name"]
        if old["guard"] != new["guard"]:
            problems.append(f"{n}: guard result differs")
        if old["copied_from_lab"] != new["copied_from_lab"]:
            problems.append(f"{n}: copy check differs")
        o_runs = {r["run_id"]: r for r in old["runs"]}
        n_runs = {r["run_id"]: r for r in new["runs"]}
        if set(o_runs) != set(n_runs):
            problems.append(f"{n}: the run matrix differs")
            continue
        for rid, o in o_runs.items():
            x = n_runs[rid]
            if o["status"] != x["status"] or o["pass"] != x["pass"]:
                problems.append(f"{rid}: recorded {o['status']}/{'pass' if o['pass'] else 'fail'}, "
                                f"rerun gives {x['status']}/{'pass' if x['pass'] else 'fail'}")
            elif not runner._same(o["errors"], x["errors"], rtol):
                problems.append(f"{rid}: errors differ beyond rtol {rtol:g}")
    if entry["score"] != benchboard.score_counts(entry["methods"]):
        problems.append("score does not match the recorded runs")
    again = benchboard.aggregate_metrics(flow.metric_specs(_paper(sd)), entry["methods"])
    if ([m["key"] for m in again] != [m["key"] for m in entry["metrics"]]
            or not all(_close(a["value"], b["value"], rtol) for a, b in zip(again, entry["metrics"]))):
        problems.append("metrics do not match the recorded runs")
    return [f"{eid}: {p}" for p in problems]
```

```js
function benchSummary() {
  const b = D.bench || {};
  const n = Object.values(b).reduce((a, r) => a + r.full.length + r.partial.length, 0);
  if (!n) return "No entries yet. Give a paper to your Claude Code or Codex setup and see how it scores.";
  const tops = Object.values(b).map((r) => r.full[0] && `${r.full[0].entrant} ${r.full[0].passed}/${r.full[0].expected}`).filter(Boolean);
  return `${n} ${n === 1 ? "entry" : "entries"}. ` + (tops.length ? `Top: ${tops.join(" · ")}` : "Partial entries only so far.");
}

const money = (x) => (x == null ? "—" : "$" + x.toFixed(2));
const kTokens = (r) => (r.input_tokens == null || r.output_tokens == null ? "—" : Math.round((r.input_tokens + r.output_tokens) / 1000) + "k");
const minutes = (s) => Math.round(s / 60) + " min";

function benchTable(rows, ranked) {
  return el("div", { class: "table-wrap" }, el("table", {},
    el("thead", {}, el("tr", {}, ["#", "agent", "setup", "score", "time", "tokens*", "cost*", "code"].map((h) => el("th", {}, h)))),

      el("td", {}, ranked ? String(i + 1) : "—"),
      el("td", {}, r.entrant),
      el("td", { class: "wrap" }, r.label || "—"),
      el("td", { class: "num" }, `${r.passed}/${r.expected}`),
      el("td", { class: "num" }, minutes(r.wall_s)),
      el("td", { class: "num" }, kTokens(r)),
      el("td", { class: "num" }, money(r.cost_usd)),
      el("td", {}, safeUrl(r.url) ? el("a", { href: r.url, target: "_blank", rel: "noopener noreferrer" }, "code") : "—"))))));
}
```

```js
// Headless check of the Bench page on the built site: it renders, the overview links to it, no console errors.
// Usage: node scripts/check_bench.mjs site
import { chromium } from "playwright";
import { spawn } from "node:child_process";

const site = process.argv[2] ?? "site";
const port = 8890 + Math.floor(Math.random() * 100);
const server = spawn("python3", ["-m", "http.server", String(port), "--bind", "127.0.0.1", "--directory", site], { stdio: "ignore" });
await new Promise((r) => setTimeout(r, 900));
const base = `http://127.0.0.1:${port}/`;
const fail = (m) => { console.error("✗ " + m); process.exitCode = 1; };
const browser = await chromium.launch();
try {
  for (const [name, url, width] of [["bench", "#bench", 1440], ["bench-phone", "#bench", 390], ["overview", "#", 1440]]) {
    const page = await browser.newPage({ viewport: { width, height: 860 } });
    const errors = [];
    page.on("pageerror", (e) => errors.push(String(e)));
    page.on("console", (m) => m.type() === "error" && errors.push(m.text()));
    await page.goto(base + url);
    await page.waitForTimeout(800);
    if (name === "overview") {
      if (!(await page.$('a.card[href="#bench"]'))) fail("overview: no Bench card");
    } else {
      const h = (await page.textContent("main h2"))?.trim();
      if (h !== "Bench") fail(`${name}: heading is ${h}`);
      const sw = await page.evaluate(() => document.scrollingElement.scrollWidth);
      if (sw > width) fail(`${name}: page scrolls sideways (${sw}px wide)`);
    }
    if (errors.length) fail(`${name}: console errors ${JSON.stringify(errors)}`);
    await page.close();
    if (!process.exitCode) console.log(`✓ ${name}`);
  }
} finally {
  await browser.close();
  server.kill();
}
```

```markdown
## Bench: bring your agent

How well does *your* agent setup reproduce a real paper? Point Claude Code or Codex, with your own model,
`AGENTS.md`/`CLAUDE.md` and skills, at a study:

    uv run raft bench --study transduced-lm-2026 --agent codex --setup ./my-setup --label "my AGENTS.md v2"
    uv run raft bench --study transduced-lm-2026 --agent claude-code --model opus
    uv run raft bench --study transduced-lm-2026 --agent codex --oss --model gpt-oss:20b   # local model, no API key
    uv run raft bench --agent command --cmd "my-agent --task {brief}"                    # any other tool

The agent works in a blind workspace: the paper's extraction and the problem's interface, with no git history,
no existing solutions, and no grader or reference numbers on disk. Paper Raft then grades its code with the
study's own measure in a copy the agent never touched, and writes an entry to `bench/results/<study>/`. Nothing the
agent says counts, only what its code does.

- `uv run raft bench --table` prints the scoreboard; the site has a **Bench** page.
- `uv run raft bench --verify` reruns every entry's code and checks its recorded numbers (CI does this on every PR).
- To join the scoreboard, read your transcript, then open a pull request with your entry folder.

Entries are graded automatically and not reviewed. Tokens, cost and time are reported by the agent's tool and are
not verified. The agent runs on your machine, where this repository's own solutions are on disk: the brief tells it
not to look, Claude Code runs without web tools, Codex runs in its workspace sandbox, and code that matches the
lab's own solver is marked copied and scores zero.
```
