# Raft App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `uv run raft app` opens a local dashboard in Paperraft's design (studies, running sessions, bench, a study's
results/flow/checker/gaps, and a Paperraft paper lookup), and `uv run raft paper <id>` prints the same for agents.

**Architecture:**
- `raft/paperraft.py` fetches and caches Paperraft's public per-paper JSON.
- `raft/app.py` builds the dashboard's JSON from the lab's own files, reusing `compare`, `studystate`, `gaps`,
  `checker`, `flow`, `live` and `benchboard`.
- `raft/watch.py` serves the new routes on the existing 127.0.0.1 server.
- The front end is a static single page under `raft/site_template/app/`. It reuses `flow.js` and `live.js` for the
  network views.

**Tech Stack:** Python 3 stdlib HTTP server, plain ES modules, CSS custom properties, Playwright check script.

**Spec:** `docs/superpowers/specs/2026-10-16-raft-app-design.md`

## Global Constraints

- Never add Co-Authored-By Claude or "Generated with Claude Code" lines to commits.
- The server binds 127.0.0.1 only, keeps the Host check, and only reads files. Ids from the browser are checked
  against the study list or the arXiv pattern `^\d{4}\.\d{4,5}$`. Anything else is a 404.
- The app has copy buttons, never run buttons. It never starts `prepare`, `bench` or an agent.
- The only network request is `https://paperaft.vercel.app/papers/<id>/index.json`, made by the local server and
  cached in `.raft/paperraft/<id>.json` for 24 hours. A stale copy is used when offline.
- Paperraft brief fields passed through: `arxiv_id, title, summary, recommendation, minimum_test, claims, source_url,
  lab_reproductions, as_of`, plus `brief_url`. Recommendation labels: `testar` → "Test it", `observar` → "Watch",
  `nao_aplica` → "Not applicable".
- Look: Be Vietnam Pro 300/500 (OFL, vendored WOFF2), wordmark in the serif stack
  `"Iowan Old Style","Palatino Linotype",Palatino,Georgia,serif`, mono labels, a rose accent `#c2185b`, a light
  paper background with a dither field that stays still under `prefers-reduced-motion`.
- Every page works at 390px wide with no sideways scroll. No console errors.
- "Paperraft's brief" and "In your lab" are separate, labelled blocks.
- Studies are read in quick mode (`studystate.stages(..., quick=True)`). The grader never runs for the app.

## Review Focus

1. A repo where `compare.build` raises (a broken `reference.json` in one study): the app must still load, with that
   study's card and an error note, not a 500 (test in Task 2).
2. Paperraft unreachable with no cache: the paper page and `raft paper` say so and still show the lab block and the
   prepare command (tests in Tasks 1 and 3).
3. A study id or arXiv id with path tricks (`../x`, `%2e%2e`, a trailing slash): 404, never a file read (test in
   Task 2).
4. A study with no `checker/`, no `gaps.json` and no runs (a fresh draft): every tab renders with plain "nothing yet"
   text, no exception (tests in Tasks 2 and 3).
5. The flow tab where WebGL is missing: the 2D fallback appears with no console error (check in Task 3, using the
   same launch flags as `check_flow.mjs`).

```python
"""Paperraft's public brief for one paper (paperaft.vercel.app/papers/<id>/index.json), cached locally.

The lab never needs it to work: offline, a saved copy is used, and without one the lab's own view still shows."""
import json
import re
import urllib.error
import urllib.request
from datetime import datetime, timedelta, timezone
from pathlib import Path

BASE = "https://paperaft.vercel.app/papers"
FIELDS = ("arxiv_id", "title", "summary", "recommendation", "minimum_test", "claims", "source_url",
          "lab_reproductions", "as_of")
LABELS = {"testar": "Test it", "observar": "Watch", "nao_aplica": "Not applicable"}
FRESH = timedelta(hours=24)
_ID = re.compile(r"(?:^|arxiv:|/papers/|/abs/|/pdf/)(\d{4}\.\d{4,5})(?:v\d+)?/?$", re.I)


def parse_id(text: str) -> str | None:
    m = _ID.search((text or "").strip())
    return m.group(1) if m else None


def default_fetch(url: str) -> bytes:
    req = urllib.request.Request(url, headers={"User-Agent": "paper-raft (+https://github.com/lusknchars/paper-raft)"})
    with urllib.request.urlopen(req, timeout=10) as r:
        return r.read()


def _keep(raw: dict, arxiv_id: str) -> dict:
    return {**{k: raw.get(k) for k in FIELDS}, "brief_url": f"{BASE}/{arxiv_id}/"}


def answer(arxiv_id: str, *, cache_dir: Path, fetch=None, now=None) -> dict:
    """{found, brief, offline, stale}. Fresh cache first, then the network, then a stale cache."""
    if parse_id(arxiv_id) != arxiv_id:
        raise ValueError(f"not an arXiv id: {arxiv_id!r}")
    now = now or datetime.now(timezone.utc)
    path = Path(cache_dir) / f"{arxiv_id}.json"
    cached = None
    try:
        cached = json.loads(path.read_text())
        at = datetime.fromisoformat(cached["fetched_at"])
        if now - at < FRESH:
            return {"found": True, "brief": cached["brief"], "offline": False, "stale": False}
    except (OSError, ValueError, KeyError, TypeError):
        cached = None
    try:
        raw = json.loads((fetch or default_fetch)(f"{BASE}/{arxiv_id}/index.json"))
    except urllib.error.HTTPError as e:
        if e.code == 404:
            return {"found": False, "brief": None, "offline": False, "stale": False}
        raw = None
    except (urllib.error.URLError, OSError, ValueError):
        raw = None
    if isinstance(raw, dict):
        brief = _keep(raw, arxiv_id)
        try:
            path.parent.mkdir(parents=True, exist_ok=True)
            path.write_text(json.dumps({"fetched_at": now.isoformat(timespec="seconds"), "brief": brief},
                                       ensure_ascii=False))
        except OSError:
            pass
        return {"found": True, "brief": brief, "offline": False, "stale": False}
    if cached:
        return {"found": True, "brief": cached["brief"], "offline": True, "stale": True}
    return {"found": False, "brief": None, "offline": True, "stale": False}


def text(root: Path, arxiv_id: str, ans: dict) -> str:
    """Plain text for agents and terminals: Paperraft's brief, then what the lab has."""
    from . import studystate
    out = []
    b = ans.get("brief")
    if b:
        out += [b.get("title") or f"arXiv:{arxiv_id}",
                f"arXiv:{arxiv_id} · Paperraft brief (as of {b.get('as_of') or 'unknown'}"
                + (", saved copy; Paperraft can't be reached" if ans.get("stale") else "") + f"): {b['brief_url']}"]
        rec = b.get("recommendation")
        if rec:
            out.append(f"Paperraft says: {LABELS.get(rec, rec)}")
        if b.get("summary"):
            out += ["", b["summary"]]
        for c in (b.get("claims") or [])[:5]:
            if isinstance(c, dict) and c.get("statement"):
                out.append(f"- {c['statement']}")
    elif ans.get("offline"):
        out.append("Paperraft can't be reached and there is no saved copy of its brief.")
    else:
        out.append(f"Paperraft has no brief for arXiv:{arxiv_id}.")
    out.append("")
    study = studystate.find_arxiv(root, arxiv_id)
    if study:
        st = studystate.stages(root, study, quick=True)
        first = next((s for s in st if s.ok is False), None)
        out += [f"In your lab: studies/{study} — " + (f"{first.name}: {first.text}" if first else "ready"),
                f"Next: {studystate.next_step(root, study, st, studystate.tools(root, study))}"]
    else:
        out += ["In your lab: no study yet",
                f"Next: uv run raft prepare --arxiv {arxiv_id} --agent <claude-code|codex>"]
    out.append(f"See it: uv run raft app --paper {arxiv_id}")
    return "\n".join(out)
```

```python
def last_stop(root, study: str) -> dict | None:
    """How the newest prepare run for the study ended, when it did not finish."""
    last = _last(Path(root), study)
    if not last or last["state"] not in ("stopped", "lost"):
        return None
    why = (last.get("problem") or {}).get("headline") or (
        "the run was interrupted (its process is gone)" if last["state"] == "lost"
        else (last["message"] or "stopped").splitlines()[0].removeprefix("raft: "))
    return {"headline": why, "at": last["updated_at"]}


def arxiv_of(paper: dict) -> str | None:
    """The study's arXiv id: `arxiv:` in paper.yaml, else the id inside an arXiv DOI (10.48550/arXiv.<id>)."""
    if paper.get("arxiv"):
        return str(paper["arxiv"])
    doi = str(paper.get("doi") or "")
    return doi.split("arXiv.", 1)[1] if "arXiv." in doi else None


def find_arxiv(root, arxiv_id: str) -> str | None:
    for s in paths.studies(Path(root), include_drafts=True):
        if arxiv_of(yaml.safe_load((Path(root) / "studies" / s / "paper.yaml").read_text()) or {}) == arxiv_id:
            return s
    return None
```

```python
import dataclasses
from datetime import date, datetime, timezone
from pathlib import Path

import yaml

from . import benchboard, checker, compare, flow, gaps, live, paths, provenance, runner, schema, studystate


def _paper(sd: Path) -> dict:
    return yaml.safe_load((sd / "paper.yaml").read_text()) or {}


def _site(root: Path) -> tuple[dict, str | None]:
    """compare.build for the non-draft studies; a broken study must not take the app down."""
    try:
        return compare.build(root, compare.repo_url(root)), None
    except Exception as e:  # noqa: BLE001
        return {"studies": [], "bench": benchboard.board(root, compare.repo_url(root), provenance.git_sha(root))}, \
            f"Results could not be read ({type(e).__name__}: {e}). Run `uv run raft compare` to see the error."


def _card(root: Path, study: str, lab: dict | None) -> dict:
    sd = root / "studies" / study
    p = _paper(sd)
    error = None
    try:
        st = studystate.stages(root, study, quick=True)
        nxt = studystate.next_step(root, study, st, studystate.tools(root, study))
    except Exception as e:  # noqa: BLE001
        st, nxt, error = [], f"uv run raft status --study {study}", f"{type(e).__name__}: {e}"
    try:
        g = gaps.load(sd)
        g = gaps.counts(g) if g else None
    except SystemExit:
        g = None
    methods = lab["methods"] if lab else []
    return {"id": study, "title": p.get("title") or study, "arxiv": studystate.arxiv_of(p),
            "doi": p.get("doi"), "authors": p.get("authors") or [], "citation": p.get("citation"),
            "draft": bool(p.get("draft")), "brief_url": p.get("brief_url"), "experiment": p.get("experiment") or "",
            "version_of": p.get("version_of"), "stages": [dataclasses.asdict(s) for s in st], "next": nxt,
            "last_stop": studystate.last_stop(root, study), "gaps": g,
            "methods": len(methods) if lab else len(runner.methods(sd)),
            "runs": sum(len(m["runs"]) for m in methods), "counts": lab["counts"] if lab else {}, "error": error}


def app_data(root) -> dict:
    root = Path(root).resolve()
    site, warning = _site(root)
    lab = {s["id"]: s for s in site["studies"]}
    cards = [_card(root, s, lab.get(s)) for s in paths.studies(root, include_drafts=True)]
    sessions = live.sessions(root)
    bench = site["bench"]
    verified = sum(r["status"] == "verified" for s in site["studies"] for m in s["methods"] for r in m["runs"])
    counts = {"studies": len(cards), "running": sum(s["state"] == "running" for s in sessions),
              "verified_runs": verified,
              "bench_entries": sum(len(v["full"]) + len(v["partial"]) for v in bench.values()),
              "open_gaps": sum((c["gaps"] or {}).get("open", 0) + (c["gaps"] or {}).get("asked", 0) for c in cards)}
    return {"generated_at": datetime.now(timezone.utc).isoformat(timespec="seconds"), "today": date.today().isoformat(),
            "repo": root.name, "studies": cards, "sessions": sessions, "bench": bench, "counts": counts,
            "warning": warning}


def study_detail(root, study: str) -> dict:
    root = Path(root).resolve()
    sd = root / "studies" / study
    site, warning = _site(root)
    lab = next((s for s in site["studies"] if s["id"] == study), None)
    out = _card(root, study, lab)
    out["warning"] = warning
    out["results"] = []
    for m in (lab or {}).get("methods", []):
        head = next((r for r in m["runs"] if r["status"] == m["headline_status"]), m["runs"][0] if m["runs"] else None)
        rv = m["review"] or {}
        out["results"].append({"name": m["name"], "status": m["headline_status"], "verdict": rv.get("verdict"),
                               "reviewer": rv.get("reviewer_agent"),
                               "passed": sum(bool(r["results"].get("pass")) for r in m["runs"]), "total": len(m["runs"]),
                               "code_url": head["code_url"] if head else None})
    if not lab:
        out["results"] = [{"name": n, "status": "no run", "verdict": None, "reviewer": None, "passed": 0, "total": 0,
                           "code_url": None} for n in runner.methods(sd)] if not out["draft"] else []
    note = sd / "checker" / "NOTE.md"
    try:
        approval = checker.approval_state(root, study)
    except schema.ContractError:
        approval = {"state": "invalid", "rounds": None, "approved_at": None}
    try:
        rounds = schema.load("checker-review", sd / "checker" / "review.json")["rounds"]
    except schema.ContractError:
        rounds = []
    out["checker"] = {"note": note.read_text() if note.is_file() else None, "approval": approval, "rounds": rounds,
                      "decoys": sorted(p.stem for p in (sd / "checker" / "attacks").glob("*.py"))}
    try:
        out["gaps_file"] = gaps.load(sd)
    except SystemExit:
        out["gaps_file"] = None
    try:
        out["letter"] = gaps.letter(root, study, compare.repo_url(root)) if out["gaps_file"] else None
    except SystemExit:
        out["letter"] = None
    out["bench"] = site["bench"].get(study) or {"full": [], "partial": []}
    try:
        out["flow"] = flow.build_flow(root, study, compare.repo_url(root))
    except Exception:  # noqa: BLE001 (the flow tab says it could not be drawn)
        out["flow"] = None
    return out
```

```js
// A quiet ordered-dither field behind the page, in Paperraft's manner: a 4x4 Bayer threshold over a slow sine field.
// Drawn small and scaled up; still when the user prefers reduced motion; never blocks the page.
(function () {
  const canvas = document.getElementById("field");
  if (!canvas || !canvas.getContext) return;
  const ctx = canvas.getContext("2d");
  if (!ctx) return;
  const bayer = [0, 8, 2, 10, 12, 4, 14, 6, 3, 11, 1, 9, 15, 7, 13, 5];
  const still = window.matchMedia("(prefers-reduced-motion: reduce)").matches;
  const cell = 4;
  let w = 0, h = 0, img = null;
  function size() {
    w = Math.ceil(window.innerWidth / cell); h = Math.ceil(window.innerHeight / cell);
    canvas.width = w; canvas.height = h; img = ctx.createImageData(w, h);
    canvas.style.imageRendering = "pixelated";
  }
  function draw(t) {
    const d = img.data;
    for (let y = 0; y < h; y++) for (let x = 0; x < w; x++) {
      const v = 0.5 + 0.25 * Math.sin(x * 0.045 + t) + 0.25 * Math.sin(y * 0.06 - t * 0.7 + Math.sin(x * 0.02));
      const on = v * 16 > bayer[(y & 3) * 4 + (x & 3)];
      const k = (y * w + x) * 4;
      d[k] = 214; d[k + 1] = 150; d[k + 2] = 172; d[k + 3] = on ? 150 : 0;
    }
    ctx.putImageData(img, 0, 0);
  }
  size();
  window.addEventListener("resize", () => { size(); draw(0); });
  if (still) { draw(0); return; }
  let last = 0;
  (function loop(ms) {
    if (ms - last > 120) { draw(ms / 6000); last = ms; }  // about 8 frames a second is enough for a background
    requestAnimationFrame(loop);
```
