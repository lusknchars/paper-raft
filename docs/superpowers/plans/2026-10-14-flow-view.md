# Flow View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw each study as glowing cables (paper → extracted items → methods → runs → results) with chain percentages and ML-readable results, shown on Paperraft's paper page, on a Flow tab of the Paper Raft site, and live on localhost with `raft watch`.

**Architecture:** paper-raft builds one `flow.json` per study from committed files (`raft/flow.py`, checked by `raft/contracts/flow.schema.json`). One plain ES module, `raft/site_template/flow/flow.js` (three.js + bloom, 2D fallback), draws it everywhere. The Pages site, `raft watch` (stdlib HTTP server on 127.0.0.1 plus progress files written by the runner) and Paperraft (a committed snapshot plus vendored copies of the module and three.js) all reuse it.

**Tech Stack:** Python 3.11+, jsonschema, pyyaml, pytest (paper-raft); pydantic 2, pytest (ai-radar); three.js 0.186.1 (MIT, vendored); Playwright 1.63.0 for the headless check (Node 22).

**Spec:** `docs/superpowers/specs/2026-10-14-flow-view-design.md`

## Rulings on the spec (made while planning)

- **three.js is vendored in paper-raft** (`raft/site_template/vendor/three-0.186.1/`), not loaded from jsDelivr: `raft watch` must work offline, and Paperraft needs the same files. Cost if wrong: about 2.1 MB in the repo.
- **A metric applies to a run when its `from` error key is present** (plus an optional `where` params filter). The spec's `claims` filter is dropped: claims are not recorded in `results.json`.
- **ai-radar validates the snapshot with a pydantic mirror** of the schema (it has no jsonschema dependency).
- **Paperraft serves the snapshot as `papers/<id>/lab-flow.json`** and the page fetches it when the section scrolls into view; it is not embedded in `index.json`.
- **The export command is `raft flow-export`**, and it refuses a study with uncommitted changes.

## Global Constraints

- No `Co-Authored-By: Claude` or "Generated with Claude Code" lines in any commit or PR, in either repo.
- Never edit any `studies/*/problem/` file (it would make every committed run stale). `paper.yaml` is outside `problem/` and may change.
- Never commit PDFs. Never lower a tolerance.
- three.js version is exactly `0.186.1`, copied byte-for-byte from the npm package. No GSAP anywhere.
- Every string from data reaches the DOM through `textContent`, never `innerHTML`.
- No simulated numbers anywhere; `raft watch` shows only progress files written by this machine's runs.
- `raft watch` binds `127.0.0.1` only.
- Pushing, opening PRs, merging and deploying are owner-gated: stop and ask at each **Owner gate**.
- Paperraft's demo does not change the brief's editorial status and does not go in a deep report.

## Review Focus

1. **A study with failed, missing or stale runs:** the flow still builds; those runs show as `failed` / `not run` / `stale` and never count as passing. (Task 1 tests.)
2. **Metric values of `1e300`** (raft's stand-in for inf/NaN): shown as `∞`, never as `1e+300σ`. (Task 4 `formatMetric`, checked in Task 5's headless check via a unit call.)
3. **Opening `site/index.html` from disk (file://):** module imports fail; the Flow box shows "needs the site served over http" and every other view still works. (Task 5.)
4. **Phone width (390 px):** no sideways page scroll; the items layer collapses to one node per kind. (Task 5 headless check.)
5. **Hostile text in a snapshot** (a title with `</script>` or `<img onerror>`): nothing executes on Paperraft; the snapshot is fetched as JSON and drawn with `textContent`. (Task 10 test.)

```python
"""One study's flow: paper → extracted items → methods → runs, built from committed files only.

The flow view (raft/site_template/flow/flow.js) draws this shape. The Paper Raft site, `raft watch` and
Paperraft's demo all read it; raft/contracts/flow.schema.json checks it.
"""
import json
import re
import shutil
from datetime import datetime, timezone
from importlib.resources import files
from pathlib import Path

import yaml

from . import provenance, runner, schema
from .status import derive_status

THREE = "three-0.186.1"
FORMATS = ("sigma", "drop_percent", "sci", "kept_percent", "percent", "number")
AGGS = ("max", "min", "mean")
_REQUIRED = {"key", "from", "label", "note", "agg", "format"}


def template_dir() -> Path:
    return Path(str(files("raft.site_template")))


def _load(path: Path):
    return json.loads(path.read_text()) if path.is_file() else None


def authors_short(paper: dict) -> str:
    authors = paper.get("authors") or []
    year = re.search(r"\b(?:19|20)\d{2}\b", paper.get("citation", ""))
    name = authors[0].split()[-1] + (" et al." if len(authors) > 1 else "") if authors else ""
    return " ".join(p for p in (name, year.group(0) if year else "") if p)


def metric_specs(paper: dict) -> list[dict]:
    """The `metrics` list of paper.yaml: which error keys the flow view shows, and how."""
    specs = paper.get("metrics") or []
    if not isinstance(specs, list):
        raise ValueError("paper.yaml: metrics must be a list")
    seen = set()
    for i, s in enumerate(specs):
        if not isinstance(s, dict) or not _REQUIRED <= set(s) or set(s) - _REQUIRED - {"where"}:
            raise ValueError(f"paper.yaml: metrics[{i}] needs exactly the keys {sorted(_REQUIRED)} (and optionally where)")
        if s["format"] not in FORMATS:
            raise ValueError(f"paper.yaml: metrics[{i}] format {s['format']!r} is not one of {FORMATS}")
        if s["agg"] not in AGGS:
            raise ValueError(f"paper.yaml: metrics[{i}] agg {s['agg']!r} is not one of {AGGS}")
        if not isinstance(s.get("where", {}), dict):
            raise ValueError(f"paper.yaml: metrics[{i}] where must map parameters to values")
        if not re.fullmatch(r"[a-z][a-z0-9_]*", str(s["key"])) or s["key"] in seen:
            raise ValueError(f"paper.yaml: metrics[{i}] key {s['key']!r} must be a unique snake_case name")
        seen.add(s["key"])
    return specs


def case_key(params: dict) -> str:
    return ",".join(f"{k}={params[k]}" for k in sorted(params))


def case_label(params: dict) -> str:
    return " · ".join(str(params[k]) for k in sorted(params))


def _expected(sd: Path) -> list[dict]:
    try:
        return runner.expand(sd, {})
    except Exception:  # a draft's problem/ may not run yet
        return []


def _run(sd: Path, root: Path, name: str, params: dict, review, sha_now, specs) -> dict:
    rid = runner.run_id(name, params)
    run = {"run_id": rid, "method": name, "params": params, "case": case_key(params),
           "status": "missing", "pass": False, "started_at": None, "metrics": []}
    mpath = sd / "runs" / rid / "manifest.json"
    if not mpath.is_file():
        return run
    manifest = schema.load("manifest", mpath)
    results = schema.load("results", mpath.parent / "results.json")
    stale = (provenance.inputs_hash(manifest["params"], sd / "problem") != manifest["inputs_hash"]
             or sha_now != manifest["method_sha"])
    run["status"] = "stale" if stale else derive_status(results, manifest, review)
    run["pass"] = bool(results["pass"]) and not stale
    run["started_at"] = manifest["started_at"]
    errors = results.get("errors") or {}
    run["metrics"] = [{"key": s["key"], "value": float(errors[s["from"]])} for s in specs
                      if s["from"] in errors and all(params.get(k) == v for k, v in s.get("where", {}).items())]
    return run


def build_flow(root: Path, study: str, repo: str | None = None) -> dict:
    root = Path(root).resolve()
    sd = root / "studies" / study
    paper = yaml.safe_load((sd / "paper.yaml").read_text()) or {}
    specs = metric_specs(paper)
    reference = _load(sd / "problem" / "reference.json") or {}
    items = [{"id": i["id"], "kind": i["kind"]} for i in (_load(sd / "extraction.json") or {}).get("items", [])]
    ids = {i["id"] for i in items}
    names = runner.methods(sd)
    combos = _expected(sd) if names else []
    methods, runs = [], []
    for color, name in enumerate(names):
        mjson = _load(sd / "methods" / name / "method.json") or {}
        review = _load(sd / "reviews" / f"{name}.json")
        sha_now = provenance.method_sha(root, sd / "methods" / name)
        mine = [_run(sd, root, name, p, review, sha_now, specs) for p in combos]
        statuses = {r["status"] for r in mine}
        status = ("no run" if statuses <= {"missing"} else "failed" if "failed" in statuses
                  else "verified" if statuses == {"verified"} else "unverified")
        methods.append({"name": name, "implements": [i for i in mjson.get("implements", []) if i in ids],
                        "status": status, "color": color})
        runs += mine
    out = {
        "schema": 1, "study": study,
        "source": {"repo": repo, "commit": provenance.git_sha(root),
                   "built_at": datetime.now(timezone.utc).isoformat(timespec="seconds")},
        "paper": {"title": str(paper.get("title", study)), "authors_short": authors_short(paper),
                  "reference_checked": bool(reference.get("verified_against_pdf")), "draft": bool(paper.get("draft"))},
        "items": items, "methods": methods,
        "cases": [{"key": case_key(p), "label": case_label(p)} for p in combos],
        "runs": runs,
        "metrics": [{k: s[k] for k in ("key", "label", "note", "agg", "format")} for s in specs],
    }
    schema.check("flow", out)
    return out


def copy_assets(dest: Path) -> None:
    """flow.js, flow.css and three.js, laid out as Paperraft serves them: <dest>/paper-raft-flow, <dest>/three-…"""
    tpl = template_dir()
    shutil.copytree(tpl / "vendor" / THREE, Path(dest) / THREE, dirs_exist_ok=True)
    (Path(dest) / "paper-raft-flow").mkdir(parents=True, exist_ok=True)
    for name in ("flow.js", "flow.css"):
        shutil.copyfile(tpl / "flow" / name, Path(dest) / "paper-raft-flow" / name)


def export(root: Path, study: str, out: Path, assets: Path | None, repo: str | None) -> dict:
    """Write a committed study's flow to `out` (and the view's files to `assets`), for Paperraft."""
    if provenance.is_dirty(root, [root / "studies" / study]):
        raise SystemExit(f"raft: studies/{study} has uncommitted changes; commit them before exporting")
    data = build_flow(root, study, repo)
    out = Path(out)
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_text(json.dumps(data, indent=1, ensure_ascii=False) + "\n")
    if assets is not None:
        copy_assets(Path(assets))
    return data
```

const FORMATS = {
  sigma: (v) => v.toFixed(1) + "σ",
  drop_percent: (v) => "−" + Math.round(100 * (1 - v)) + "%",
  sci: (v) => v.toExponential(1),
  kept_percent: (v) => (100 * (1 + v)).toFixed(1) + "%",
  percent: (v) => (100 * v).toFixed(1) + "%",
  number: (v) => String(Number(v.toPrecision(3))),
};
const AGG = { max: (a) => Math.max(...a), min: (a) => Math.min(...a), mean: (a) => a.reduce((x, y) => x + y, 0) / a.length };

export function formatMetric(format, v) {
  if (typeof v !== "number" || Number.isNaN(v)) return "—";
  if (!Number.isFinite(v) || Math.abs(v) >= HUGE) return "∞";
  return (FORMATS[format] || FORMATS.number)(v);
}

export const pct = (n, d) => (d ? Math.round((100 * n) / d) + "%" : "—");

/** The chain's numbers for a selection: { method?: name, case?: key }. */
export function chain(data, sel = {}) {
  const ms = data.methods.filter((m) => !sel.method || m.name === sel.method);
  const names = new Set(ms.map((m) => m.name));
  const runs = data.runs.filter((r) => names.has(r.method) && (!sel.case || r.case === sel.case));
  const ids = new Set(data.items.map((i) => i.id));
  const used = new Set(ms.flatMap((m) => m.implements).filter((id) => ids.has(id)));
  const metrics = data.metrics.map((m) => {
    const vals = runs.flatMap((r) => r.metrics.filter((x) => x.key === m.key).map((x) => x.value));
    return { ...m, text: vals.length ? formatMetric(m.format, AGG[m.agg](vals)) : "—" };
  });
  return {
    items: data.items.length, implemented: used.size,
    methodsTotal: ms.length, methodsVerified: ms.filter((m) => m.status === "verified").length,
    runsExpected: runs.length, runsPassing: runs.filter((r) => r.pass && r.status !== "stale").length,
    metrics,
  };
}

function h(tag, cls, text) {

function seeded(seed) {

function makeGL() {

  composer.addPass(new RenderPass(scene, camera));

  composer.addPass(bloom);
  composer.addPass(new OutputPass());

}

      for (let v = 0; v < U.length; v++) {

        if (pulsing && c.live) { const d = U[v] - ((t * 0.5 + c.ph) % 1); a += 0.16 * Math.exp(-(d * d) / 0.002) * c.f; }
        col[v * 3] = c.rgb.r * a; col[v * 3 + 1] = c.rgb.g * a; col[v * 3 + 2] = c.rgb.b * a;
      }
      gl.lines.geometry.attributes.color.needsUpdate = true;
      gl.composer.render();

      ctx.strokeStyle = `rgba(${Math.round(c.rgb.r * 255)},${Math.round(c.rgb.g * 255)},${Math.round(c.rgb.b * 255)},${a})`;
      ctx.beginPath(); ctx.moveTo(c.a.x, c.a.y); ctx.bezierCurveTo(c.c1.x, c.c1.y, c.c2.x, c.c2.y, c.b.x, c.b.y); ctx.stroke();
    }

    """progress(fraction) for solve(): clamps to [0, 1], ignores junk, writes at most twice a second."""

```python
"""raft watch: the flow view on localhost, with live progress from this machine's runs. Nothing goes online."""
import http.server
import json
import webbrowser
from pathlib import Path

from . import flow

TYPES = {".html": "text/html; charset=utf-8", ".js": "text/javascript; charset=utf-8",
         ".css": "text/css; charset=utf-8", ".json": "application/json"}


def read_progress(study_dir: Path) -> dict:
    out = {}
    for p in sorted((Path(study_dir) / "runs" / ".progress").glob("*.json")):
        try:
            out[p.stem] = json.loads(p.read_text())
        except (OSError, json.JSONDecodeError):
            continue
    return out


def make_server(root: Path, study: str, port: int) -> http.server.ThreadingHTTPServer:
    root, static = Path(root).resolve(), flow.template_dir().resolve()
    sd = root / "studies" / study

    class Handler(http.server.BaseHTTPRequestHandler):
        def _send(self, body: bytes, ctype: str) -> None:
            self.send_response(200)
            self.send_header("Content-Type", ctype)
            self.send_header("Cache-Control", "no-store")
            self.send_header("Content-Length", str(len(body)))
            self.end_headers()
            self.wfile.write(body)

        def do_GET(self):  # noqa: N802 (http.server's name)
            path = self.path.split("?", 1)[0]
            if path in ("/", "/index.html"):
                return self._send((static / "flow" / "watch.html").read_bytes(), TYPES[".html"])
            if path == "/flow.json":
                return self._send(json.dumps(flow.build_flow(root, study)).encode(), TYPES[".json"])
            if path == "/progress.json":
                return self._send(json.dumps(read_progress(sd)).encode(), TYPES[".json"])
            target = (static / path.lstrip("/")).resolve()
            if target.is_relative_to(static) and target.is_file() and target.suffix in TYPES:
                return self._send(target.read_bytes(), TYPES[target.suffix])
            self.send_error(404)

        def log_message(self, *args):
            pass

    return http.server.ThreadingHTTPServer(("127.0.0.1", port), Handler)


def serve(root: Path, study: str, port: int, open_browser: bool) -> None:
    srv = make_server(root, study, port)
    url = f"http://127.0.0.1:{srv.server_address[1]}/"
    print(f"✓ watching {study} at {url} (local only; Ctrl-C to stop)", flush=True)
    if open_browser:
        webbrowser.open(url)
    try:
        srv.serve_forever()
    except KeyboardInterrupt:
        pass
    finally:
        srv.server_close()
```
